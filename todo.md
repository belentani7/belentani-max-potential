## Current direction

- Product: interactive audiovisual web artwork / game-like artist website.
- Narrative: BELENTANI / JUDAS EXPERIENCE / The Fall of a Sovereign.
- Visual language: cyberpunk + space opera + desert/industrial ruin + luxury music campaign.
- Runtime: React + TypeScript + Three.js/WebGL with WebGPU-ready boundaries and fallback rendering.
- Interaction: scroll as camera travel, cursor as look control, objects as portals, archive as escape room.
- Primary human imagery: user-provided photos and verified public artist imagery only.
- Generated media: abstract shaders/textures/UI symbols/environmental non-human assets only.
- First playable slice: system boot → orbital relic field → city/desert transition → archive → Judas Protocol unlock.
- Accessibility: reduced motion, low-power mode, keyboard escape routes, readable HUD, touch-friendly controls.
- Performance targets: capped DPR, adaptive particle counts, lazy scene activation, no unbounded per-frame allocations.
