# Matriz de Auditoría Punto por Punto — BELENTANI

## Requisitos extraídos del prompt y adjuntos

1. **"El archivo se autoexplica. Mejoralo."** → Exigencia de analizar la estructura previa y elevar drásticamente su calidad y profundidad.
2. **"Solo tienes 300 créditos. Usa el máximo potencial."** → Máxima optimización de recursos, código robusto, sin dependencias innecesarias de pago, aprovechando capacidad nativa del sandbox.
3. **"Busca en GitHub, busca el cantante, usa Mon Amour la canción si quieres tenemos derechos."** → Integración explícita de referencias al artista, su música ("Mon Amour") y la narrativa asociada.
4. **"Máximo potencial cubre todos los campos, máximo visual."** → Estándar estético de nivel mundial (tipo Awwwards/FWA), tipografía intencional, profundidad, motion design, paleta sofisticada.
5. **"Rehazlo de cero siguiendo todo nuevo plan."** → Descarte de la estructura anterior plana o simplista; arquitectura inmersiva.
6. **"No generes fotos mías. Usa las de Dribbble / Google Fotos, solo genera para algún asset."** → Respeto estricto por la autoría y origen de las fotos reales del artista; prohibición de generar rostros humanos o falsas fotos del cantante con IA; uso de assets generados únicamente para texturas, UI abstracta o entornos.
7. **"No quiero plano, quiero una página como videojuego inmersivo de las que ganan premios mundiales, el código más complejo."** → Interfaz 3D interactiva, capas espaciales, shaders, HUD diegético, navegación por sectores y escape room narrativo.
